# Neapolis Cafe Website ☕️

This repository contains the source code, localization files, and static assets for the official website of **Neapolis Cafe** ([neapoliscafe.com](https://neapoliscafe.com)).

---

### 🌐 Features
* **Multi-language Support** — Full localization available in both English and Greek/Italian (`/en` and `/el` directories).
* **High Performance** — Lightweight static architecture deployed via GitHub Pages for maximum uptime and speed.
* **Responsive Design** — Fully optimized for mobile devices, tablets, and desktops.

---

### 📂 Repository Structure
* `/el` — Greek localization source files and localized pages.
* `/en` — English localization source files and localized pages.
* `/images` — Optimized graphics, product photos, and branding assets.
* `index.html` — Main entry point and language router.

---

### 🛠 Tech Stack
* **Frontend:** Clean HTML5, Modern CSS3, and Vanilla JavaScript.
* **Hosting & Deployment:** GitHub Pages with custom domain routing.
